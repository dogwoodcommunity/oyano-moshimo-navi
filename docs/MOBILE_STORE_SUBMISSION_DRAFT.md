## 説明文候補

親のことを、ひとりで抱え込まない。

「今日は食事がとれた」「病院から連絡があった」。親のもしもナビは、親御さんの小さな変化や家族で確認したいことを整理する手帳です。

- 日々の様子を短く記録し、あとから見返せます。
- 家族で確認することをまとめ、担当や進み具合を整理できます。
- 書類の保管場所や実家について、文字でメモを残せます。
- AI相談では、相談する人の手帳を選び、保存された記録を参考に、次に確認することや相談の準備を整理できます。
- 保存済みのAI回答や相談履歴から、問題のある回答をアプリ内で報告できます。報告には、調査担当者による該当の相談文・回答の確認への同意が必要です。

手帳を利用するにはメールによる本人確認が必要です。カード登録は不要で、無料では1名分の手帳を作成し、あなたのほかに家族1人を招待できます。
無料のAI相談は家族で共有する1日1回の枠です。日本時間の翌日0時に更新され、利用には記録の保存とAI送信への同意が必要です。現在の利用可否は相談画面で確認できます。

AIの回答には誤りが含まれる場合があります。診断・治療・法律や税務の専門判断、緊急時の対応を代行するものではありません。
入力前に、ご本人の同意と家族の共有範囲を確認し、必要な範囲だけ記録してください。
暗証番号、パスワード、マイナンバーなどは入力しないでください。

※上記は現ソースの説明候補。無料枠は `packages/shared/src/plan.ts`・native利用案内・相談APIと照合したが、ログイン後の実配信版での受入は未完。
※対象者選択・切替時の表示分離・同意付き通報は実装と合成試験まで完了。通報の運営担当/確認頻度/保管期間/本番受入が未確定のため、現時点で提供開始を宣言しない。
※「写真/PDFを添付」「全記録を永久に保存」「すべて覚えている」「24時間必ず返答」は現段階では記載しない。
※相談履歴は原則として相談した本人だけが確認する。家族で共有する手帳・長期要約と、本人が通報調査に同意した1件の運営閲覧を混同しない。通報は個別の返信や緊急対応を約束する窓口ではない。

## 審査担当者向けメモの骨子

- 本アプリは家族の記録・整理を支援するもので、医療診断や緊急通報サービスではない。
- ログイン後の確認手順: 手帳を選択 → 記録作成 → 再読込 → 確認項目 → 対象者とAI同意 → 質問/回答 → 履歴/記憶の確認 → 問題の報告（理由・閲覧同意・受付確認）→ 設定/削除依頼。
- 通報は保存済み回答の本人所有権を確認して受け付ける。運営画面は管理者allowlistとMFAが必要で、審査用の一般アカウントに管理権限を付けない。失敗時の受付未確認・再試行も確認する。
- 課金商品/外部購入リンクは今回の提出対象ではない。AI利用条件は実版に合わせる。
- nativeの手帳はメール確認後に利用する。登録なしで読める急なときの案内と、Web側のメール登録なし相談機能（既定OFF）を混同しない。後者をnativeの提供機能として申告しない。
- **審査用のアクセス手段は未準備。** メール認証を都度待たず確認できる正規の審査用アカウント/手段を設計し、期限/回数制限も調整して実試験する。認証バイパスや全利用者共通の秘密を埋め込まない。
- 審査用認証情報は承認後のConsoleの専用欄だけへ登録し、この資料/Git/チャットへ書かない。
