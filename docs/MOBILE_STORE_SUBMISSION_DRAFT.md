## 説明文候補

親のことを、ひとりで抱え込まない。

「今日は食事がとれた」「病院から連絡があった」。親のもしもナビは、親御さんの小さな変化や家族で確認したいことを整理する手帳です。

- 日々の様子を短く記録し、あとから見返せます。
- 家族で確認することをまとめ、担当や進み具合を整理できます。
- AI相談では、保存された記録を参考に、次に確認することや相談の準備を整理できます。

AIの回答には誤りが含まれる場合があります。診断・治療・法律や税務の専門判断、緊急時の対応を代行するものではありません。
入力前に、ご本人の同意と家族の共有範囲を確認し、必要な範囲だけ記録してください。
暗証番号、パスワード、マイナンバーなどは入力しないでください。

※AI相談の利用条件/上限・対象者選択の完成状況は、実配信版を確認したうえで追記する。
※「写真/PDFを添付」「全記録を永久に保存」「すべて覚えている」「24時間必ず返答」は現段階では記載しない。

## 審査担当者向けメモの骨子

- 本アプリは家族の記録・整理を支援するもので、医療診断や緊急通報サービスではない。
- ログイン後の確認手順: 手帳を選択 → 記録作成 → 再読込 → 確認項目 → AI同意 → 質問/回答 → 履歴/記憶の確認 → 設定/削除依頼。
- 課金商品/外部購入リンクは今回の提出対象ではない。AI利用条件は実版に合わせる。
- **審査用のアクセス手段は未準備。** メール認証を都度待たず確認できる正規の審査用アカウント/手段を設計し、期限/回数制限も調整して実試験する。認証バイパスや全利用者共通の秘密を埋め込まない。
- 審査用認証情報は承認後のConsoleの専用欄だけへ登録し、この資料/Git/チャットへ書かない。
