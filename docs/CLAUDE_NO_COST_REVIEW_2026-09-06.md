## 結果

2026-09-06、Claudeの実チャット「親のもしもナビ無料版の公開前確認レビュー」で回答を受領した。
既存契約枠で実施し、追加使用クレジットはOFFのまま。コード全文レビューではない。

### 回答の要点（要約）

- 書類メモと家族招待を、説明なしの人が見つけられるか再確認する。入口の追加と初見の発見は別。
- 家族・本人の権限境界、AI記憶削除後の参照範囲、中断時の入力、PDFの収録範囲を追加確認する。
- Pro契約、有料監視、任意通知、決済、製本、ネイティブアプリを無料Web公開の必須条件にしない。
- 実データのバックアップ/復旧、実端末、二者での削除、問い合わせ受信/返信、担当・代行・連絡経路は別途必要。
- モニターの継続意向は自然な継続率ではないが、自然継続率の証明自体を公開の停止条件にしない。
- 「バックアップがあれば消えない」「削除で即時に全コピーが消える」「AIが専門判断する」等の誤解を避ける。
- 法務側の最終確認をAIレビューで代替しない。実装を見ていないため本番合格とは判断できない。

### 採用・修正して扱う点

| 指摘 | 今回の対応・確認範囲 |
| --- | --- |
| 書類/招待の発見 | 隔離UIでホームから各1操作で書類入力欄/招待手順へ到達。初見の第三者による成功率・時間は未実測 |
| 中断時の保持 | 未保存本文がreloadで消えることを再現。下書きの自動保存と偽らず、未保存表示とbeforeunload警告を追加。ブラウザが警告を出さない場合やSPA内遷移までの保護は保証しない |
| 権限 | SQL/routeの合成negative試験を継続。実際の2ユーザー・2端末の受入とは分離 |
| AI削除→次回参照 | 実DELETE handlerと次回context組立を合成連続テスト。削除前の原記録が境界で除外され、削除後の新規記録が採用されることを確認 |
| PDF範囲 | 実storeと実画面の期間選択処理で、別対象者・完了済み削除・未選択のAIメモ等を合成fixture確認。ブラウザでは9月5日のみ選択し9月6日を対象外にできることを確認 |
| 運用の準備 | 既存Pro/Free外部dumpの選択肢、日次手動監視と未記入の担当/backup準備票を整理。担当決定や実backup完了とは記載しない |

Claudeの「鍵情報は本人専用であるべき」という前提は現仕様と異なる。
**書類・鍵の保管場所は家族にも共有する仕様**で、招待画面にも明記している。
暗証番号や鍵の秘密情報を保存する提案ではなく、場所メモの機能である。無断で非共有へ変更しない。

また「AI記憶を削除したら、どんな質問でも同じ情報が二度と出ない」は採用しない。
記憶削除は元の日記や本人の相談履歴の削除とは別で、相談履歴、基本情報、新たな質問などから
同じ事実が伝わる可能性がある。追加試験が確認するのは**削除境界以前の日記の自動参照を止めること**で、
モデルの完全忘却や外部AIの実回答検証ではない。有料APIを呼ぶ試験は今回行っていない。

PDF画面の準備完了はOSのPDF保存成功ではない。実iPhone/Androidの出力、
別タブで削除した後に既に開いているPDF画面が追従するかは別の未完了項目とする。
