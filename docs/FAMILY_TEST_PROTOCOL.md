# 親のもしもナビ モニターテスト手順

## 目的

正式公開前のモニターテストでは、機能の感想よりも「説明なしで使えるか」「記録を続けたいか」「Family Plusに払う理由があるか」を確認する。

## モニターへ渡すURL

- モニター専用入口: `https://oyano-moshimo-navi.vercel.app/monitor`
- 回答フォームだけ開く場合: `https://oyano-moshimo-navi.vercel.app/monitor/report`

通常は入口URLだけを渡す。入口からテスト開始と結果報告の両方へ進める。

入口の「テストを始める」は既存の記録を消さない。以前のテストデータを消す操作は、確認ダイアログ付きの別ボタンに分離している。

## テスト前の注意

- 所要時間は10〜15分。
- アプリのダウンロードは不要。スマートフォンのブラウザで確認できる。
- 実名、病名、住所、電話番号、パスワード、マイナンバーは入力しない。
- 対象者の呼び名は「お母さん」「テスト父」などのニックネームでよい。
- 操作に詰まった時はすぐに正解を教えず、止まった画面と言葉を先に記録する。

## モニターに試してもらうこと

1. 1人分の手帳を作る。
2. 「今日の記録」を1件保存する。
3. 保存した記録を見つけ、その記録をもとにAI相談を開く。
4. モニター入口へ戻り、「結果を報告する」から回答を送る。

## 観察すること

- 最初に押すボタンが分かったか。
- 手帳を作るために必要な入力が分かったか。
- 記録が保存されたことを確信できたか。
- 保存した記録をもう一度見つけられたか。
- AI相談へ迷わず進めたか。
- 文字の大きさとボタンの押しやすさに問題がなかったか。
- 7日後も自分から記録したいと思えたか。
- 家族共有、2人目の手帳、継続AI相談のどれに価値を感じたか。

## 回答で必ず確認すること

1. 説明なしでどこまで完了できたか。
2. どの画面で迷ったか。
3. 保存した記録を見つけられたか。
4. AI相談を見つけて使えたか。
5. 7日後も使いたいか。
6. 家族へ共有したいか。
7. 月980円または年9,800円を払って使いたいか。
8. 一番分かりにくかったことと、足りない機能。

## 運営側の確認先

- モニター回答一覧: `https://oyano-moshimo-navi.vercel.app/admin/monitor-feedback`
- 運営入口: `https://oyano-moshimo-navi.vercel.app/admin`

回答はSupabaseの `audit_logs` に `monitor_feedback_submitted` として保存する。管理者認証なしでは一覧を取得できない。

## 判定ライン

- 3組中2組が、手帳作成から記録1件保存まで自力で完走できる。
- 3組中2組が、保存した記録を自力でもう一度見つけられる。
- 3組中2組が、記録からAI相談へ進める。
- 3組中2組が、7日後も使いたいと答える。
- 3組中2組が、家族へ共有したいと答える。
- 3組中1組以上が、月980円または年9,800円を「払いたい」または「家族と相談したい」と答える。

## テスト中にやらないこと

- その場で新機能を約束しない。
- 医療、法律、税務の判断を断定しない。
- 危機を煽って課金に誘導しない。
- 回答を良く見せるよう誘導しない。
- 実在する親の詳細な健康情報や個人情報の入力を求めない。
