# 親のもしもナビ 家族3組テスト手順

## 目的

家族3組テストでは、機能の感想ではなく「実際に使えるか」「戻ってくるか」「980円を払う理由があるか」を確認する。

## テスト前に自分たちで済ませる実機確認

1. ログイン済みで日記に写真を追加し、保存後にlocalStorageへdata URLが残らないことを確認する。
2. 別端末または別ブラウザで同じ手帳を復元し、Storage写真が表示されることを確認する。
3. 意図的に409競合を起こし、復元後も未送信の日記が消えないことを確認する。

## テスト対象

- 親の入院、退院後の在宅、介護、実家じまい、死後手続きのどれかに不安がある家族。
- できれば兄弟姉妹など、家族共有が起こりそうな世帯を優先する。

## 渡すURL

- 初回導線: `https://oyano-moshimo-navi.vercel.app/start?fresh=1`
- すでに登録済みの確認: `https://oyano-moshimo-navi.vercel.app/home`

## 初回に見てもらうこと

1. 1人目を登録する。
2. 状況を1つ選ぶ。
3. 整理結果を見る。
4. 1人目の手帳に登録する。
5. プロフィールを少し埋める。
6. 日記を1件書く。
7. 写真を1枚添付する。
8. 確認リストを1件編集する。

## 観察すること

- どの画面で指が止まったか。
- どの言葉が分からなかったか。
- 「保存」「共有」「相談」「2人目追加」の意味が伝わったか。
- 途中でログインやメール確認に抵抗があったか。
- 写真添付や日記が「手帳らしい」と感じられたか。

## 必ず聞く質問

1. 最初から最後まで、自分ひとりで登録できそうでしたか。
2. 7日後に、この手帳へ自分から戻ってきそうですか。
3. 家族にも共有したいと思いましたか。
4. AI相談が本当にこの人の記録を読んで答えるなら、使いたいですか。
5. 2人目も管理できて、家族共有とAI相談が使えるなら、月980円または年9,800円を払いますか。

## 聞かない質問

- 便利ですか。
- 良いと思いますか。
- いくらなら払いますか。

## 判定ライン

- 3組中2組が、初回登録から日記1件まで自力で完走できる。
- 3組中2組が、家族共有したいと答える。
- 3組中1組以上が、月980円または年9,800円を「払う」または「家族に相談する」と答える。
- 3組中2組が、7日後にもう一度触る理由を言える。

## テスト中にやらないこと

- その場で新機能を約束しない。
- 医療、法律、税務の判断を断定しない。
- 危機を煽って課金に誘導しない。
- 操作に詰まった時、すぐ助けずに、どこで詰まったかを先に記録する。
