# 親のもしもナビ 7日間モニター募集文

## 募集サイト掲載用（そのまま貼り付け）

### 仕事内容

親の介護や「もしもの時」に備えて、家族で記録・共有するWebアプリ（公開前）を7日間ご利用いただき、感想をお聞かせください。

### やっていただくこと

1. お送りするURLをスマートフォンで開き、親御さんの呼び名、関係、都道府県、市区町村を入力して初期設定する。呼び名と地域は仮名・架空の内容でよい。クラウド保存は任意。
2. 1日1回を目安に、7日間で「今日の記録」を3回以上書く。内容はダミー・仮名でよい。
3. 保存した過去の記録を見返し、確認リスト、書類の所在メモ、AI相談をそれぞれ1回試す。家族招待は画面を開いて手順を確認する（実際の送信は任意）。
4. 開始日を1日目とした8日目の0:00以降、手帳の先頭に出る案内からアプリ内の専用フォーム（15〜20分）へ回答し、気になった画面のスクリーンショットを1枚以上、最大3枚添付する。

### 応募条件

- 親または義理の親が要介護・要支援、もしくは今後介護の可能性を感じている方（40〜60代歓迎）。
- iPhoneまたはAndroidでWebサイトを利用できる方。
- 「分かりにくい」「使わない」と率直に回答できる方。

### 報酬・期間

- 報酬: 2,000円/人（最終回答の提出で支払い）。機能を使えなかった場合も報酬は同じです。
- 募集締切: 掲載から3日。
- 作業期間: URL送付後7日間。

### お願い

- 未公開サービスのため、画面や内容をSNS等へ投稿しないでください。
- 7日間は同じスマートフォン・同じブラウザを使い、プライベートブラウズを使ったり履歴・サイトデータを削除したりしないでください。
- 本名、住所、病名、医療情報、メールアドレスなどの個人情報は入力しないでください。仮名・架空の内容で構いません。
- 最終報告に添付するスクリーンショットにも、個人情報を写さないでください。
- 回答とスクリーンショットはサービス改善だけに使い、6か月後に削除します。希望があればクラウドワークスのメッセージからいつでも削除を依頼できます。

### 応募時にお答えください

1. 介護している、または備えている相手との関係。
2. 現在の状況（詳細な病名や個人情報は不要）。
3. 普段、介護や家族の情報共有に利用しているアプリやツール。

## 採用後に送る文面

開始ページはこちらです。

https://oyano-moshimo-navi.vercel.app/monitor

初日に呼び名・関係・都道府県・市区町村を入力して1人分の手帳を作ってください。クラウド保存は任意です。7日間は同じスマホ・同じブラウザを使い、履歴を削除せず、1日1回を目安に「今日の記録」を3回以上書いてください。テストの地域は架空の内容で構いません。期間中に過去の記録を見返し、確認リスト、書類の所在メモ、AI相談を各1回試してください。家族招待は画面を開いて手順を確認するだけで、招待の送信は任意です。

開始日を1日目として、8日目の0:00以降に手帳の先頭へ「お疲れさまでした。最後に回答をお願いします」と表示されます。そこから最終報告へ進んでください。フォームでは、ご自身のプロフィール画面に表示されているクラウドワークス名を入力してください。モニター番号はありません。

最終日の報告フォームはこちらです。

https://oyano-moshimo-navi.vercel.app/monitor/report

実名・住所・病名などは入力せず、仮名と架空の内容で構いません。迷った場所、使えなかったこと、使わないと感じた理由も、遠慮なくそのままお知らせください。最終回答を提出いただければ、使えた機能の数に関係なく報酬は同じです。

## 運営用メモ

- モニター入口: `https://oyano-moshimo-navi.vercel.app/monitor`
- 最終報告: `https://oyano-moshimo-navi.vercel.app/monitor/report`
- 回答管理: `https://oyano-moshimo-navi.vercel.app/admin/monitor-feedback`
- 回答と画像は管理者認証なしでは閲覧できない。
- 参加人数は固定しない。参加者は最終フォームで、自分のクラウドワークス表示名を入力する。
- 最終回答の提出で報酬を支払う。機能未達や記録中断を減額・不払いの理由にしない。
- 管理画面で自己申告と端末の自動カウントを並べ、差も調査結果として記録する。
- 別の支払管理表へ、表示名、提出日時、支払状態、削除予定日、削除依頼の有無を残す。
