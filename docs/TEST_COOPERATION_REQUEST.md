# 親のもしもナビ テスト協力のお願い文

## LINE・メールでそのまま送る文面

親のもしもナビのモニターテストにご協力ください。

親や家族の変化を日々記録し、その記録をもとに次に確認することや相談内容を整理する「家族の手帳」を作っています。正式公開前のため、実際にスマートフォンで触って、分かりにくいところを教えていただきたいです。

所要時間は10〜15分ほどで、アプリのダウンロードは不要です。

試していただきたいことは4つです。

1. 1人分の手帳を作る
2. 今日の記録を1件保存する
3. 保存した記録を見つけてAI相談を開く
4. 最後に同じページから結果を報告する

モニターテストはこちらです。

https://oyano-moshimo-navi.vercel.app/monitor

実名・病名・住所・電話番号などは入力せず、「お母さん」「テスト父」などのニックネームや架空の内容で大丈夫です。

褒めてもらうためのテストではなく、どこで迷ったかを知るためのテストです。遠慮なく正直に教えていただけると助かります。

## 短いLINE用

親のもしもナビのモニターテストをお願いします。所要時間は10〜15分、アプリのダウンロードは不要です。

1人分の手帳を作る→記録を1件保存→その記録からAI相談を開く→結果報告、の順に試してください。

https://oyano-moshimo-navi.vercel.app/monitor

実名や病名は入れず、ニックネームや架空の内容で大丈夫です。迷った場所を正直に教えてください。

## 口頭での説明

これは、親や家族の変化を記録し、あとで家族に説明したり、次に確認することを整理したりする手帳です。

今日は、初めて使うつもりで1人分の手帳を作り、記録を1件保存して、その記録をもとにAI相談を開いてみてください。操作に迷っても、すぐ答えを聞かず、どこで迷ったかを覚えておいてください。最後に専用フォームへ回答をお願いします。
