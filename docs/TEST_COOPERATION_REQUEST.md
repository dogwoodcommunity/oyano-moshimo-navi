# 親のもしもナビ 7日間モニター募集文

## 募集サイト掲載用

### 仕事内容

親の介護や「もしもの時」に備えて、家族で記録・共有するWebアプリ（公開前）を7日間ご利用いただき、感想をお聞かせください。

### やっていただくこと

1. お送りするURLをスマートフォンで開き、親御さんの呼び名と関係だけを入力して初期設定する。
2. 7日間、1日1回「今日の記録」を書く（合計7回）。内容はダミー・仮名でよい。
3. 確認リスト、書類の所在メモ、家族招待をそれぞれ1回試す。
4. 7日間の終了後、手帳の先頭に出る案内から専用フォーム（約15問・15分）へ回答し、気になった画面のスクリーンショットを3枚添付する。

### 応募条件

- 親または義理の親が要介護・要支援、もしくは今後介護の可能性を感じている方（40〜60代歓迎）。
- iPhoneまたはAndroidでWebサイトを利用できる方。
- 「分かりにくい」「使わない」と率直に回答できる方。

### 報酬・期間

- 報酬: 2,000円/人（検収後に支払い）。
- 募集締切: 掲載から3日。
- 作業期間: URL送付後7日間。

### お願い

- 未公開サービスのため、画面や内容をSNS等へ投稿しないでください。
- 本名、住所、病名、医療情報、メールアドレスなどの個人情報は入力しないでください。仮名・架空の内容で構いません。
- 最終報告に添付するスクリーンショットにも、個人情報を写さないでください。

### 応募時にお答えください

1. 介護している、または備えている相手との関係。
2. 現在の状況（詳細な病名や個人情報は不要）。
3. 普段、介護や家族の情報共有に利用しているアプリやツール。

## 採用後に送る文面

この度は「親のもしもナビ」7日間モニターへご協力いただき、ありがとうございます。

開始ページはこちらです。

https://oyano-moshimo-navi.vercel.app/monitor

初日に1人分の手帳を作り、7日間、1日1回「今日の記録」を書いてください（合計7回）。期間中に確認リスト、書類の所在メモ、家族招待も各1回お試しください。

テスト開始から7日後、手帳の先頭に「お疲れさまでした。最後に回答をお願いします」と表示されます。そこから最終報告へ進んでください。

最終日の報告フォームはこちらです。

https://oyano-moshimo-navi.vercel.app/monitor/report

実名・住所・病名などは入力せず、仮名と架空の内容で構いません。迷った場所や使わないと感じた理由も、遠慮なくそのままお知らせください。
