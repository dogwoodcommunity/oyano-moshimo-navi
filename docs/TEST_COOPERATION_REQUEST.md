# 親のもしもナビ テスト協力のお願い文

## LINE/メール用

突然すみません。いま「親のもしもナビ」という、親や家族の入院・介護・亡くなった後の手続き・実家じまいを、家族で整理するための手帳アプリを作っています。

まだ正式リリース前なので、3組だけ実際に触ってもらい、「分かりにくいところ」「本当に使いたいと思うか」を見せてもらいたいです。

お願いしたいことは、スマホで以下の流れを試してもらうことです。

1. 1人目の手帳を作る
2. 今の状況を1つ選ぶ
3. 整理結果を見る
4. 日記を1件書く
5. 写真を1枚添付してみる
6. 家族に共有したいと思うか教えてもらう

所要時間は15分ほどです。医療・法律・税務の判断をするものではなく、家族で確認することを整理するためのものです。

テスト用URL:
https://oyano-moshimo-navi.vercel.app/start?fresh=1

見たいのは「褒めてもらうこと」ではなく、どこで迷うか、どこが不安かです。遠慮なく正直に言ってもらえると助かります。

## 口頭説明用

これは、親や家族に何かあった時に、家族で見る手帳を作るアプリです。

まず1人だけ無料で登録できます。入院、退院後の在宅、介護、亡くなった後、実家じまいなど、近い状況を選ぶと、今確認することがリストになります。

その後、日々の記録や写真を残せます。将来的には、家族共有、2人目以降の管理、記録をもとにした相談機能を有料で出す予定です。

今日は、実際に触ってもらって「分かりにくいところ」と「980円なら払うと思うか」を聞かせてください。
