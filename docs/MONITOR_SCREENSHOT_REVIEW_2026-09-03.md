# モニター添付画像の匿名レビュー（2026-09-03）

## 確認方法とプライバシー

本番の管理者画面から、モニター最終回答に添付された14件を読み取り専用で確認した。
14件すべてを開くことができ、欠損は確認されなかった。画像のダウンロード、編集、削除、回答データの変更は
行っていない。

画像には入力済みプロフィールが見えるものもあったため、氏名、入力内容、Storageの保存パス、画像そのものは
この資料へ残さない。以下では `A01` から `A14` の匿名番号と、プロダクト画面の種類だけを扱う。

## 画面別の内訳

| 分類 | 件数 | 主な見え方 |
| --- | ---: | --- |
| 今日の記録・手帳 | 5 | 説明や補足が長く、保存操作まで縦に離れる画面がある |
| 履歴・記録詳細 | 4 | 月まとめ、記録、操作、ナビ補足が連続し、記録本文が埋もれやすい |
| 初期登録・プロフィール | 2 | 日付等の入力欄が多く、入力済み情報を含むため取扱注意 |
| クラウド保存 | 1 | 右側の内容が切れ、狭い画面で横にはみ出していた |
| 急なとき | 1 | 手順は見えるが、縦に長い |
| 最終回答フォーム | 1 | サービス本体ではなくモニター回答画面 |

PDF・印刷、書類の所在メモ、家族招待そのものが写る添付はなかった。

## 匿名の画像別確認

- `A01`、`A10`: 履歴の記録詳細。本文より操作や補足を読む距離が長い。
- `A02`、`A14`: 初期登録またはプロフィール。入力済み情報が見えるため内容は転記しない。
- `A03`、`A04`、`A07`、`A08`: 今日の記録。項目選択、音声入力説明、保存操作が縦に並ぶ。
- `A05`: 履歴カレンダー。画像上で明確な崩れは確認されなかった。
- `A06`: 月のまとめ。狭いカード内で文字の折り返しが多い。
- `A09`: クラウド保存。右端の切れと横方向のはみ出しを確認した。
- `A11`: 手帳上部。画像上で明確な崩れは確認されなかった。
- `A12`: 急なとき。内容が縦に長い。
- `A13`: モニター最終回答フォーム。プロダクト本体の操作評価からは分ける。

## 再設計への反映

- 今日と履歴を別タブに分け、記録本文を先に表示し、長いナビ補足を折り畳む。
- 記録、書類、家族、AIへの近道を手帳上部にまとめる。
- クラウド保存カード内の見出し、説明、メール入力、状態表示、ボタンが390px幅からはみ出さないようにする。
- PDFは添付画像では確認できなかったため、保存と紙印刷を分離し、日付範囲、写真枚数上限、読み込み期限、
  写真を外して本文だけ保存する手段をコードとローカル操作で確認する。

## 残る確認

- iPhoneとAndroidの実機で、OSの印刷画面からPDF保存先またはプリンター選択まで進めるか。
- 公開後のクラウド保存画面が、実際の長いメールアドレスや家族名でも横にはみ出さないか。
- 次の無誘導テストで、記録本文を見つける時間、履歴到達、書類メモ保存、招待リンク作成が改善するか。

この分類は添付者が「気になった」画面の傾向を示す。回答で選ばれた迷いの場所と画像が一致しない場合もあるため、
画像だけを不具合の直接証拠または利用人数として数えない。
