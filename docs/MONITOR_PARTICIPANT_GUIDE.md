# 親のもしもナビ 7日間モニター参加ガイド

このたびは「親のもしもナビ」のモニターにご協力いただき、ありがとうございます。説明どおりに使えなかった場合も、その事実が大切な調査結果です。最後の回答を提出いただければ、使えた機能の数にかかわらず報酬は同じです。

## 最初に知っておいてほしいこと

- 期間は、開始した日を1日目とする7日間です。
- 7日間は同じスマートフォン・同じブラウザを使ってください。
- プライベートブラウズは使わず、ブラウザの履歴やサイトデータを削除しないでください。
- 本名、住所、病名、電話番号、メールアドレスなどの個人情報は入力しないでください。呼び名・地域・記録内容は仮名や架空の内容で構いません。
- 未公開サービスのため、画面や内容をSNS・ブログなどへ投稿しないでください。
- 途中で困っている方を把握するため、画面で同意した場合に限り、開始日、最終利用日時、記録した日数、各機能を試したかどうかを、名前を含まない端末識別番号とともに運営側へ送信します。呼び名、地域、記録本文、写真、相談内容は途中経過として送信しません。最終回答後は、途中経過と入力したクラウドワークス名が紐づきます。途中経過もモニター終了後6か月を目安に削除します。

## 開始ページ

スマートフォンで次のURLを開いてください。

<https://oyano-moshimo-navi.vercel.app/monitor>

## 1日目にすること

1. 「7日間のテストを始める」を押します。
2. 親御さんの呼び名、関係、都道府県、市区町村を入力します。テスト用の仮名・架空の地域で構いません。
3. 「この人の手帳を作る」を押します。
4. 手帳の「今日の記録を書く」から、その日の記録を1件保存します。

クラウド保存は任意です。設定すると、端末の故障やブラウザの履歴削除があった時に、メール確認で手帳データを戻しやすくなります。設定しなくてもモニターには参加できます。

## 1日目から7日目までにすること

### 7日間で3回以上すること

- 1日1回を目安に、手帳の「今日の記録を書く」から7日間で3回以上記録を保存してください。1日目に保存した記録も3回に含まれます。
- 毎日書けない日があっても大丈夫です。内容は1行でも、架空の出来事でも構いません。

### 7日間のどこかで各1回試すこと

- 保存した過去の記録を見返す。
- 「確認すること」を開き、項目を1つ操作する。
- 「書類の場所」を開き、所在メモを試す。
- 「AIに相談する」を1回試す。
- 「家族と共有する」を開き、招待の手順を見る。実際に招待を送る必要はありません。

全部できなかった場合も、そのままで大丈夫です。どこで迷ったか、何が見つからなかったかを最後に教えてください。

## 最後の回答はいつ出るか

開始日を1日目として、8日目の午前0時から回答できます。7日目の当日ではなく、7日間が終わった翌日です。

8日目になると、手帳の上部に「お疲れさまでした。最後に回答をお願いします」と表示されます。表示を押して最終回答へ進んでください。

案内を見失った場合は、同じスマートフォン・同じブラウザで次のURLを開いてください。

<https://oyano-moshimo-navi.vercel.app/monitor/report>

## 最終回答ですること

1. ご自身のクラウドワークスのプロフィールに表示されている名前を、そのまま入力します。モニター番号はありません。
2. 使えたこと、迷ったこと、使わないと思った理由を回答します。
3. 気になった画面のスクリーンショットを1枚以上、最大3枚添付します。
4. 個人情報が写っていないことを確認し、送信します。

回答時間の目安は15〜20分です。最終回答の提出をもって報酬のお支払い対象になります。

## 困った時

- 画面が動かない、保存できたか分からない、機能が見つからない時は、無理に正解を探さなくて構いません。
- 可能であれば、その画面のスクリーンショットを残してください。
- クラウドワークスのメッセージで、使っている端末と迷った画面をお知らせください。
- 途中で記録できない日があっても、モニターをやめず、8日目の最終回答まで進んでください。

## 回答と画像の取り扱い

回答とスクリーンショットはサービス改善の目的だけに使い、提出から6か月後に削除します。期限前の削除を希望する場合は、クラウドワークスのメッセージからいつでもご連絡ください。
