# 親のもしもナビ ロゴ素材

用途別のロゴ素材です。

スマホや資料にそのまま貼る場合はPNG、印刷会社やデザイナーへ渡す場合はSVGを使ってください。

- `oyano-moshimo-logo-horizontal.svg`
  - チラシ、資料、Webヘッダー向けの横組みロゴ。
- `oyano-moshimo-logo-horizontal.png`
  - チラシ、資料、Notion、Googleスライドなどにそのまま貼れる横組みPNG。
- `oyano-moshimo-logo-horizontal-transparent.png`
  - 背景透過の横組みPNG。色付き背景やCanvaに載せる時はこちら。
- `oyano-moshimo-logo-stacked.svg`
  - 表紙、SNS画像、カードの中央配置向けの縦組みロゴ。
- `oyano-moshimo-logo-stacked.png`
  - 表紙やSNS画像に使いやすい縦組みPNG。
- `oyano-moshimo-logo-mark.svg`
  - アイコン単体。小さい場所やファビコン的な使い方。
- `oyano-moshimo-logo-mark.png`
  - アイコン単体のPNG。アプリアイコン、SNS、チラシのワンポイント向け。
- `oyano-moshimo-logo-png.zip`
  - PNG一式をまとめた配布用ZIP。

色:

- 文字: `#26353B`
- 見守り鳥の線: `#33424A`
- 帽子: `#4A8FA6`
- くちばし: `#E8A15D`
- 背景: `#FFFDF8`

印刷会社へ渡す場合はSVGを渡すのが一番きれいです。スマホで保存・共有する時はPNGまたはZIPを使ってください。
