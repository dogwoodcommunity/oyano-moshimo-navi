# 親のもしもナビ ロゴ素材

用途別のSVGロゴです。

- `oyano-moshimo-logo-horizontal.svg`
  - チラシ、資料、Webヘッダー向けの横組みロゴ。
- `oyano-moshimo-logo-stacked.svg`
  - 表紙、SNS画像、カードの中央配置向けの縦組みロゴ。
- `oyano-moshimo-logo-mark.svg`
  - アイコン単体。小さい場所やファビコン的な使い方。

色:

- 文字: `#26353B`
- 見守り鳥の線: `#33424A`
- 帽子: `#4A8FA6`
- くちばし: `#E8A15D`
- 背景: `#FFFDF8`

印刷会社へ渡す場合は、まずSVGをPDFまたはPNGに書き出して使ってください。
