# 無料ユーザー中心の再設計（2026-09-03）

## 判断

次の開発段階は、有料会員を増やす段階ではなく、無料で記録価値を感じ、過去を見返し、家族へ共有する人を
増やす段階とする。

根拠は現行フォーム版の11回答である。

- 継続意向あり: 6/11
- 家族共有に前向き・条件付き前向き: 9/11
- AI相談を利用できた: 11/11
- 書類メモを利用完了できなかった: 8/11
- 家族招待を手順確認まで完了できなかった: 7/11
- 月980円または年払いへの直接の支払意向: 0/11

有償の指定課題による探索的モニターであり、自然利用の継続率・紹介率を証明した数字ではない。今回の実装後は、
無誘導の無料利用で改めて確認する。

## 体験の順番

```text
無料で1人分の手帳を作る
  → 今日の様子を1行記録する
  → 保存できたことを確認する
  → 過去の記録を見返す
  → 書類・鍵の保管場所を残す
  → 家族1人へ招待リンクを送る
```

AI相談は「今日の記録」と「保存完了」から使う。毎日1回無料とし、利用済みの日は翌日0時から再び無料で
使えることを主案内にする。

## 今回の実装

- 手帳の最上部を対象者名、保存先、今日の記録、4つの近道に絞る。
- `今日 / 履歴 / 情報 / 確認 / 写真` のタブを常時表示する。
- 過去の記録を今日の入力画面から分離し、日付選択後は対象記録まで移動する。
- 記録がないカレンダー日は操作不可にし、「すべての記録に戻る」へ表現を統一する。
- 記録本文を先に見せ、ナビの長い補足は「ヒントを見る」に折り畳む。
- 書類・鍵メモへホームから直接移動し、入力欄を開いてフォーカスする。
- 家族招待は、ログイン前にも3手順を表示する。
- 招待リンク作成と送信を別状態にし、作成後は「まだ相手に届いていない」と明示する。
- 記録と基本情報は端末への永続化成功を判定し、失敗時は完了扱い・計測・フォーム消去を行わない。
- 日常導線とAIの当日上限画面からPlus・980円の訴求を外す。
- 料金ページでは無料プランを主役にし、Plusは必要になった時の選択肢へ下げる。
- 手帳タブに選択状態と対応領域を読み上げる属性を付け、スマホでは固定ヘッダーと重ならないようにする。
- 新しい匿名計測の種類と目的をプライバシー表示へ追記する。
- PWAのキャッシュ版を更新し、古い画面が残りにくいようにする。
- モニター添付14件を匿名分類し、クラウド保存カードの横はみ出しを390px幅で解消する。
- 思い出の手帳はPDF保存と紙印刷を別操作にし、日付範囲選択、写真拡大、写真12枚上限を追加する。
- 写真または認証の読み込みが終わらない場合も期限で解除し、写真を外して本文だけ保存・印刷できるようにする。

## 計測

匿名の端末ID、イベント名、時刻だけを用い、次を操作回数として集計する。

- `history_viewed`: 過去の記録を開いた
- `document_memo_saved`: 書類・鍵の保管場所を新規保存・変更した
- `family_invite_created`: 招待リンクを作成した
- `family_invite_shared`: OSの共有画面で送信操作を完了した

作成と送信を分ける。本文、メールアドレス、表示名、写真はこの計測へ含めない。匿名端末IDなので、操作回数を
そのまま人数として扱わない。

## 受け入れ条件

- 390px幅で対象者名、保存先、今日の記録、AI・家族・履歴・書類の近道が横にはみ出さない。
- ホームから履歴、書類・鍵メモ、家族招待へ1操作で到達できる。
- 記録保存に失敗した時は「未保存」と表示し、入力内容を残して再試行できる。
- 保存直後から同じ記録を開き、編集またはAI相談へ進める。
- 履歴の日付を押すと、その日の記録一覧へ移動する。記録のない日は押せない。
- 招待リンクを作っただけの状態を「送信済み」と表示しない。
- 無料枠を使っている日常画面にPlusや980円を常時表示しない。
- 390px幅のクラウド保存カードで、説明、メール入力、保存状態、操作ボタンが横にはみ出さない。
- PDFは日付範囲を選べ、保存と紙印刷を区別でき、写真読込が失敗しても本文だけなら先へ進める。
- 次の無誘導テストで、履歴到達、書類メモ保存、招待リンク作成を各80%以上にする。
